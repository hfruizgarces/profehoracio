    Elige una herramienta y toca el tablero para colocarla.

    Cómo funciona

    Toca una herramienta y luego una casilla del tablero para colocarla. El robot 🤖, la llave 🔑 y el interruptor ◈ son únicos: tocar otra casilla los mueve. Las puertas con llave se abren con ACTIVAR parado justo frente a ellas (tras recoger la llave). La puerta con interruptor se abre activando el interruptor a distancia. Usa 🧹 para vaciar una casilla.
